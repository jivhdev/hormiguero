# Hormiguero

Familia de aplicaciones de escritorio para Windows, gratuitas y de código abierto, pensadas para que cualquier oficinista las configure a su medida.

> **Estado:** en definición. Todavía no hay aplicaciones publicadas.

## Estructura

```
Hormiguero                 ecosistema
└── Obrera                 ambiente de oficina
    ├── Archivero          entrada: reconoce y archiva los documentos que llegan
    ├── Buscadero          consulta y control: busca, muestra y hace seguimiento
    └── Mensajero          salida: prepara correos, mensajes y datos para terceros
```

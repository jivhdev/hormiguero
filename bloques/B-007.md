# B-007 — Base de datos común

## Objetivo

Que el núcleo cree y abra la base común SQLite en modo WAL y le aplique sus migraciones (N-001 de `semillas/Nucleo/SPEC.md`, ADR-001).

## Contenido exacto

1. Agrega el paquete `Microsoft.Data.Sqlite` (última versión estable) a `Directory.Packages.props` y su referencia, sin versión, en `Hormiguero.Nucleo.csproj`.
2. `Datos/BaseComun.cs`: clase `BaseComun` con:
   - `static string RutaPorDefecto` = `%LOCALAPPDATA%\Hormiguero\hormiguero.db`.
   - `static SqliteConnection Abrir(string ruta)`: crea la carpeta si no existe, abre la conexión, activa `PRAGMA journal_mode=WAL` y `PRAGMA busy_timeout=5000`, aplica las migraciones pendientes y devuelve la conexión abierta.
3. `Datos/Migraciones.cs`: clase estática `Migraciones` con una lista ordenada de pares (versión, SQL) y un método que crea la tabla `migraciones(version INTEGER PRIMARY KEY, aplicada_en TEXT NOT NULL)` y aplica, en una transacción por migración, solo las versiones que faltan. La lista empieza con una sola migración, versión 1: tabla `configuracion(clave TEXT PRIMARY KEY, valor TEXT NOT NULL)`.
   - Regla "solo agregar" (ADR-001): antes de aplicar, si el SQL de una migración contiene `DROP ` o `RENAME` (sin importar mayúsculas), lanza `InvalidOperationException`.
4. `tests/Hormiguero.Nucleo.Tests/BaseComunTests.cs`: pruebas xUnit, cada una con una ruta temporal propia (nunca la ruta por defecto), que se borra al terminar.

## Casos límite

- La carpeta de la base no existe: se crea.
- Se abre dos veces la misma base: la segunda no vuelve a aplicar migraciones.
- Una migración con `DROP TABLE` o `ALTER TABLE x RENAME`: se rechaza con excepción y la base queda como estaba.
- Dos conexiones abiertas a la vez: una escribe 100 filas en `configuracion` mientras la otra lee; ninguna falla.

## Criterio de término

- Pruebas: `Crea_la_base_y_la_carpeta`, `Queda_en_modo_WAL`, `No_repite_migraciones`, `Rechaza_migracion_que_borra_o_renombra`, `Dos_conexiones_leen_y_escriben_a_la_vez`. Todas pasan con `dotnet test`.
- `dotnet build` sin advertencias; `dotnet csharpier check .` sin errores.

# B-021 — Agrupar resultados

## Objetivo

Convertir la lista de documentos encontrados en resultados para mostrar: cada documento una sola vez, con sus versiones y carpetas (REQ-004 de `semillas/Buscadero/SPEC.md`; casos C1, C3, C4). Lógica pura: no toca disco ni base de datos.

## Contenido exacto

1. `Agrupador.cs`:
   - `record VersionDocumento(string Etiqueta, IReadOnlyList<string> Rutas, DocumentoIndexado Principal)`: `Etiqueta` ∈ `original`, `cedible`, `escaneado`; `Rutas` = todas las copias exactas (misma huella).
   - `record ResultadoBusqueda(string Titulo, string Numero, string Tipo, IReadOnlyList<VersionDocumento> Versiones, IReadOnlyList<string> Carpetas, DateTime Modificado)`; `Titulo` = tipo y número (`"OCC 104523"`, o solo `"104523"` si no hay tipo); `Carpetas` = carpetas distintas donde aparece; `Modificado` = el más reciente.
   - `static IReadOnlyList<ResultadoBusqueda> Agrupar(IReadOnlyList<DocumentoIndexado> documentos, string numero)`:
     1. **Copias exactas (C1):** documentos con la misma huella (no nula) son una sola versión con varias rutas.
     2. **Tipo:** el prefijo del número buscado en el nombre del archivo (origen `nombre`), en mayúsculas; si el número se encontró solo en el texto, tipo vacío.
     3. **Mismo resultado:** versiones con el mismo número y el mismo tipo.
     4. **Etiqueta:** sufijo `CEDIBLE` (sin importar mayúsculas) → `cedible` (C4); si no tiene texto y su estado es `correcto` → `escaneado` (C3); si no, `original`.
     5. **Orden de versiones:** `original`, `escaneado`, `cedible`. La primera es la que se abre.
     6. **Orden de resultados:** el más reciente primero.
2. `AgrupadorTests.cs`.

## Casos límite

- Mismo PDF (misma huella) en dos carpetas: 1 resultado, 1 versión con 2 rutas, `Carpetas` con 2 (C1).
- `FCV25001.pdf` y `FCV25001_CEDIBLE.pdf`: 1 resultado "FCV 25001" con versiones `original` y luego `cedible` (C4).
- `5521.pdf` escaneado y `5521.pdf` con texto, distinta huella, mismo tipo vacío: 1 resultado con `original` y `escaneado` (C3).
- `OCC104523.pdf` y `FCV104523.pdf`: 2 resultados distintos (tipos distintos).
- Lista vacía: lista vacía.

# B-002 — Configuración común de .NET

## Objetivo

Crear la configuración que comparten todos los proyectos .NET del monorepo.

## Contenido exacto

1. `global.json`: SDK `10.0.401` con `rollForward: latestFeature`.
2. `Directory.Build.props`: `Nullable` enable, `ImplicitUsings` enable, `LangVersion` latest, `TreatWarningsAsErrors` true, `Deterministic` true, `Authors` Javier, `Product` Hormiguero. No fijar `TargetFramework` aquí (cada proyecto pone el suyo).
3. `Directory.Packages.props`: `ManagePackageVersionsCentrally` true y una entrada `PackageVersion` por cada paquete de pruebas: `Microsoft.NET.Test.Sdk`, `xunit`, `xunit.runner.visualstudio`, `coverlet.collector`. Usa la última versión estable de cada uno (consúltala con `dotnet package search <nombre> --exact-match`).

## Casos límite

- Ningún archivo usa `TargetFramework` global.
- Las versiones son estables (sin `-preview`, `-rc` ni `-beta`).
- Los tres archivos son XML/JSON válidos.

## Criterio de término

- `dotnet --version` dentro de la carpeta responde `10.0.x` (usa global.json).
- Los tres archivos existen y `git status --short` solo muestra esos tres.

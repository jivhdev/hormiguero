# B-009 — Leer información de un PDF

## Objetivo

Que el núcleo informe páginas, si tienen texto y las palabras con su posición, sin caerse nunca (N-003 de `semillas/Nucleo/SPEC.md`, ADR-002: PdfPig).

## Contenido exacto

1. Agrega `UglyToad.PdfPig` (última versión estable) a `Directory.Packages.props` y su referencia, sin versión, en `Hormiguero.Nucleo.csproj`.
2. `Pdf/LectorPdf.cs`:
   - `enum EstadoPdf { Correcto, Danado, Protegido }`
   - `record PalabraPdf(string Texto, int Pagina, double X, double Y, double Ancho, double Alto)` (coordenadas en puntos PDF).
   - `record InfoPdf(EstadoPdf Estado, int Paginas, IReadOnlyList<bool> PaginaTieneTexto, IReadOnlyList<PalabraPdf> Palabras)` con propiedad `TieneTexto` = alguna página con texto.
   - `static InfoPdf Leer(Stream contenido)`: abre con PdfPig. Una página "tiene texto" si tiene más de 20 letras. Si PdfPig lanza error de clave o cifrado → `Protegido`; cualquier otro error → `Danado`. Nunca lanza excepción.
   - El método recibe un `Stream` (no una ruta) para que quien llama lea el archivo en memoria y nunca lo deje bloqueado (D-60).
3. `tests/.../PdfDePrueba.cs`: ayudante que genera PDF en memoria con `PdfDocumentBuilder` de PdfPig: uno con texto (incluye la palabra `104523`), uno de 2 páginas sin texto (solo un rectángulo dibujado), y bytes de PDF truncados para el caso dañado. Nunca se usan documentos reales.
4. `tests/.../LectorPdfTests.cs`.

## Casos límite

- PDF con texto: `TieneTexto = true` y entre sus palabras está `104523` con página 1 y coordenadas mayores a 0.
- PDF sin texto: `TieneTexto = false`, `Paginas = 2`, `Estado = Correcto`.
- Bytes truncados o basura: `Estado = Danado`, sin excepción.
- Stream vacío: `Estado = Danado`, sin excepción.

## Criterio de término

- Pruebas: `Lee_palabras_con_coordenadas`, `Detecta_pdf_sin_texto`, `Pdf_truncado_es_danado`, `Stream_vacio_es_danado`. Todas pasan.
- `dotnet build` sin advertencias; `dotnet csharpier check .` sin errores; licencias permitidas.

# B-029 — Texto dentro de una zona del PDF

## Objetivo

Leer el texto que queda dentro de un rectángulo marcado en una página (Archivero: asistente A2 y reconocimiento, `semillas/Archivero/SPEC.md` REQ-002 y REQ-003).

## Contenido exacto

`ZonaPdf.cs` en el espacio de nombres `Hormiguero.Nucleo.Pdf`:

```csharp
// Rectángulo en puntos PDF, con origen abajo a la izquierda (como PdfPig).
public record Zona(int Pagina, double X, double Y, double Ancho, double Alto);

public static class ZonaPdf
{
    public static string Texto(InfoPdf info, Zona zona);
}
```

- Toma las palabras de `info.Palabras` (`PalabraPdf`, ya existe en `LectorPdf.cs`) de la página `zona.Pagina` (la primera página es 1, como `PalabraPdf.Pagina`) cuyo **centro** queda dentro del rectángulo (bordes incluidos).
- Las ordena por líneas, de arriba hacia abajo, y dentro de cada línea de izquierda a derecha. Dos palabras están en la misma línea si sus centros verticales difieren en menos de la mitad de la altura de la más baja.
- Las une con un espacio dentro de la línea y con un espacio entre líneas. Devuelve `""` si no hay palabras.
- `ArgumentNullException` si `info` o `zona` son null; `ArgumentOutOfRangeException` si `Ancho` o `Alto` son ≤ 0.

`ZonaPdfTests.cs` (arma `InfoPdf` a mano con `PalabraPdf`, sin archivos):

- `Toma_solo_las_palabras_dentro`
- `Ordena_por_lineas_de_arriba_hacia_abajo`
- `Palabra_cortada_por_el_borde_cuenta_por_su_centro`
- `Otra_pagina_no_cuenta`
- `Zona_vacia_devuelve_texto_vacio`
- `Zona_sin_tamano_lanza_error`

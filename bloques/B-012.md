# B-012 — Huella de un archivo

## Objetivo

Calcular la huella SHA-256 de un archivo sin cargarlo entero en memoria y sin bloquearlo (N-007 de `semillas/Nucleo/SPEC.md`; caso C1).

## Contenido exacto

1. `Utilidades/Huella.cs`: `static string Calcular(string ruta)` → hexadecimal en minúsculas. Abre con `FileShare.ReadWrite | FileShare.Delete` (otro programa puede mover o borrar el archivo mientras se lee) y lee por partes con `SHA256.HashData(Stream)` o equivalente.
2. `tests/.../HuellaTests.cs` con archivos temporales propios.

## Casos límite

- Mismo contenido, distinto nombre: huellas iguales.
- Un byte distinto: huellas distintas.
- Archivo vacío: la huella conocida de SHA-256 vacío (`e3b0c442...b855`).
- Mientras se calcula, otro proceso puede abrir el archivo para escribir (no queda bloqueado).

## Criterio de término

- Pruebas: `Mismo_contenido_misma_huella`, `Un_byte_distinto_cambia_la_huella`, `Archivo_vacio`, `No_bloquea_el_archivo`. Todas pasan.
- `dotnet build` sin advertencias; `dotnet csharpier check .` sin errores.

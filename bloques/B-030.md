# B-030 — Ruta y nombre de destino de un documento

## Objetivo

Calcular dónde y con qué nombre se guarda un documento reconocido (`semillas/Archivero/SPEC.md`: REQ-003 pasos 4 y 5, REQ-004 ceros a la izquierda y cedibles; D-62).

## Contenido exacto

`DestinoArchivo.cs` en `Hormiguero.Archivero.Logica`:

```csharp
public enum FormaCarpeta { AnioYMes, SoloAnio, Directo }

public enum ParteNombre { Tipo, Emisor, Numero, NombreOriginal, Fecha }

public record ReglaDestino(
    string CarpetaMadre,
    FormaCarpeta Forma,
    IReadOnlyList<ParteNombre> Partes,
    string Separador
);

public record DatosDocumento(
    string Tipo,
    string Emisor,
    string Numero,
    string NombreOriginal,   // con extensión, por ejemplo "scan_0001.pdf"
    DateOnly Fecha,
    bool EsCedible
);

public static class DestinoArchivo
{
    public static string Carpeta(ReglaDestino regla, DateOnly fecha);
    public static string Nombre(ReglaDestino regla, DatosDocumento datos);
    public static string Ruta(ReglaDestino regla, DatosDocumento datos);
}
```

- `Carpeta`: `AnioYMes` → `CarpetaMadre\2026\202610`; `SoloAnio` → `CarpetaMadre\2026`; `Directo` → `CarpetaMadre`.
- `Nombre`: une las partes con `Separador` y agrega `.pdf`.
  - `Tipo`, `Emisor`: tal cual, sin espacios al inicio ni al final.
  - `Numero`: sin ceros a la izquierda (`000104523` → `104523`; `0000` → `0`).
  - `NombreOriginal`: sin la extensión.
  - `Fecha`: `yyyy-MM-dd`.
  - Si `EsCedible`, agrega `_CEDIBLE` antes de `.pdf` (D-62), salvo que el nombre ya termine en `CEDIBLE` (sin distinguir mayúsculas).
  - Cambia por `-` los caracteres no válidos en nombres de Windows (`Path.GetInvalidFileNameChars()`).
  - Si las partes quedan vacías, `InvalidOperationException`.
- `Ruta`: `Path.Combine(Carpeta(regla, datos.Fecha), Nombre(regla, datos))`.

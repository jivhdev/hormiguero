# B-042 — Ventana "Configuraciones"

## Objetivo

Ver y editar las configuraciones de identificación por emisor y tipo (REQ-007 de `semillas/Archivero/SPEC.md`). Editar o borrar una configuración no mueve ni renombra documentos ya guardados (REQ-004).

## Reglas de estilo (obligatorias)

- Sin frameworks MVVM ni comandos propios (ADR-002 de Buscadero, ADR-001 de Archivero): manejadores `Click` en el code-behind. Copia la forma de `src/Hormiguero.Buscadero/PantallaCarpetas.xaml(.cs)`, incluidos los atajos con `PreviewKeyDown` de la ventana (`Keyboard.Modifiers == ModifierKeys.Alt` y `e.SystemKey`) suscritos en `Loaded` y quitados en `Unloaded`.
- Solo recursos de `Hormiguero.Diseno` con `DynamicResource` (`Hormiguero.Fondo`, `Hormiguero.Superficie`, `Hormiguero.Borde`, `Hormiguero.Texto`, `Hormiguero.TextoSecundario`, `Hormiguero.TextoTitulo`, `Hormiguero.TextoNormal`, `Hormiguero.Margen`, `Hormiguero.Radio`, `Hormiguero.Principal`, `Hormiguero.Acento`, `Hormiguero.Aviso`, `Hormiguero.Error`, `Hormiguero.Exito`). Sin identificadores con tilde ni ñ.
- En un proyecto WPF agrega `using System.IO;` si usas `File`, `Path` o `Directory`.
- Textos visibles: exactamente los de este bloque.

## API existente (no se cambia)

- `Hormiguero.Nucleo.Datos.Identificaciones(SqliteConnection)`: `Listar()` (ordenadas por emisor y tipo), `bool Quitar(long id)`; `record Identificacion(long Id, string Tipo, string Emisor, string Datos)`.
- `Hormiguero.Archivero.Logica.ConfiguracionArchivo.DeJson(string)` → tiene `Destino` (`ReglaDestino` con `CarpetaMadre`, `Forma`, `Partes`, `Separador`) y `ZonaFecha` (`Zona?`).

## Contenido exacto

1. `VentanaConfiguraciones.xaml` (Window): título "Configuraciones", 900 × 640, `WindowStartupLocation="CenterOwner"`, fondo `Hormiguero.Fondo`.
   - Arriba: "Cada configuración le enseña a Archivero a reconocer un tipo de documento de un emisor. Cambiarla no mueve los documentos que ya están guardados."
   - Lista agrupada por emisor (título del grupo = emisor). Cada fila: el tipo en grande; debajo, en `Hormiguero.TextoSecundario`, "Se guarda en: <CarpetaMadre>" y la forma ("año y mes", "solo año" o "directo"); botones "Editar" y "Quitar".
   - Si no hay ninguna: "Todavía no hay configuraciones. Aparecen al identificar el primer documento."
   - Abajo: "Cerrar" (Escape).
2. `VentanaConfiguraciones.xaml.cs`:
   - Constructor `VentanaConfiguraciones(SqliteConnection conexion)`.
   - "Editar": dispara `public event EventHandler<Identificacion>? Editar;` (la ventana principal pide un PDF de ejemplo y abre el asistente). Después de eso se puede llamar `public void Refrescar()` para recargar la lista.
   - "Quitar": confirma con `MessageBox` "¿Quitar la configuración <tipo> de <emisor>? Los documentos ya guardados no se tocan." (Sí/No); si es Sí, `Quitar(id)` y refresca.
   - Si `Datos` no se puede leer con `DeJson`, la fila muestra "Configuración dañada" en `Hormiguero.Error` y solo permite "Quitar".

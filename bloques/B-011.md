# B-011 — Números en el nombre de un archivo

## Objetivo

Separar de un nombre de archivo cada número completo con su prefijo y sufijo (N-006 de `semillas/Nucleo/SPEC.md`; casos C5 y C7).

## Contenido exacto

1. `Utilidades/NombreArchivo.cs`:
   - `record NumeroEnNombre(string Numero, string Prefijo, string Sufijo)`.
   - `static IReadOnlyList<NumeroEnNombre> Extraer(string nombreArchivo)`: trabaja sobre el nombre sin extensión. Cada secuencia continua de dígitos es un número; se le quitan los ceros a la izquierda (`"0000025001"` → `"25001"`; `"000"` → `"0"`). `Prefijo` = letras inmediatamente antes del número, ignorando espacios, `_` y `-` entre medio. `Sufijo` = letras inmediatamente después, con la misma regla. Sin letras, cadena vacía.
2. `tests/.../NombreArchivoTests.cs` con una prueba por fila de la tabla de casos límite (`[Theory]`).

## Casos límite

| Nombre | Resultado |
|---|---|
| `OCC104523.pdf` | `104523`, prefijo `OCC`, sufijo vacío |
| `FCV0000025001_CEDIBLE.pdf` | `25001`, prefijo `FCV`, sufijo `CEDIBLE` |
| `104523 recibida.pdf` | `104523`, prefijo vacío, sufijo `recibida` |
| `F-123.pdf` | `123`, prefijo `F` |
| `informe.pdf` | lista vacía |
| `OCC 104523 NVV 33120.pdf` | dos números: `104523` (prefijo `OCC`, sufijo `NVV`) y `33120` (prefijo `NVV`) |
| `""` | lista vacía, sin error |

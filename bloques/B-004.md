# B-004 — Proyecto de pruebas del núcleo

## Objetivo

Crear el proyecto de pruebas automáticas del núcleo con una prueba mínima que confirme que todo compila y corre.

## Contenido exacto

1. `tests/Hormiguero.Nucleo.Tests/Hormiguero.Nucleo.Tests.csproj`: proyecto xUnit (`dotnet new xunit`), `TargetFramework` `net10.0-windows`, referencia al proyecto `src/Hormiguero.Nucleo`. Las referencias a paquetes van **sin versión** (las versiones están en `Directory.Packages.props`).
2. `tests/Hormiguero.Nucleo.Tests/EsqueletoTests.cs`: una sola prueba llamada `El_esqueleto_compila_y_corre` que verifica que el ensamblado del núcleo se puede cargar (por ejemplo, que `typeof` de algún tipo del ensamblado o `Assembly.Load("Hormiguero.Nucleo")` no es nulo). Borra el `UnitTest1.cs` de la plantilla.
3. Agrega el proyecto a `Hormiguero.slnx`.

## Casos límite

- Ningún `PackageReference` tiene atributo `Version`.
- No queda `UnitTest1.cs`.

## Criterio de término

- `dotnet test Hormiguero.slnx` pasa 1 de 1 prueba, sin advertencias.
- `git status --short` solo muestra los archivos permitidos.

## Reporte del agente

- Agregué el proyecto a `Hormiguero.slnx` dentro de una carpeta de solución `/tests/`, al lado de la existente `/src/`.

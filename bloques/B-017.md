# B-017 — Tablas comunes de documentos

## Objetivo

Que el núcleo guarde y consulte el índice de documentos en la base común, para que Buscadero (y después Archivero) lo usen sin escribir SQL propio (REQ-002 de `semillas/Buscadero/SPEC.md`; ADR-001 del ecosistema; ADR-001 de Buscadero).

## Contenido exacto

1. `Migraciones.cs`: agrega la migración versión 2 (solo agrega, nunca borra):
   - `documentos(id INTEGER PRIMARY KEY, ruta TEXT NOT NULL UNIQUE COLLATE NOCASE, carpeta_raiz TEXT NOT NULL COLLATE NOCASE, nombre TEXT NOT NULL, tamano INTEGER NOT NULL, modificado TEXT NOT NULL, huella TEXT, estado TEXT NOT NULL, tiene_texto INTEGER NOT NULL, indexado_en TEXT NOT NULL)`; `estado` ∈ `correcto`, `danado`, `protegido`, `solo_en_linea`.
   - `numeros_documento(documento_id INTEGER NOT NULL REFERENCES documentos(id) ON DELETE CASCADE, numero TEXT NOT NULL, prefijo TEXT NOT NULL, sufijo TEXT NOT NULL, origen TEXT NOT NULL)`; `origen` ∈ `nombre`, `texto`.
   - Índices: `numeros_documento(numero)`, `documentos(huella)`, `documentos(carpeta_raiz)`.
   - Activa `PRAGMA foreign_keys=ON` en `BaseComun.Abrir` solo si hace falta para el `CASCADE` (si se toca `BaseComun.cs`, avísalo en el reporte).
2. `Documentos.cs`: clase que recibe la conexión y ofrece:
   - `record DocumentoIndexado(string Ruta, string CarpetaRaiz, string Nombre, long Tamano, DateTime Modificado, string? Huella, string Estado, bool TieneTexto, IReadOnlyList<(string Numero, string Prefijo, string Sufijo, string Origen)> Numeros)`.
   - `void Guardar(DocumentoIndexado doc)`: inserta o reemplaza por `ruta` (reemplaza también sus números), en una transacción.
   - `void Quitar(string ruta)`.
   - `IReadOnlyDictionary<string, (long Tamano, DateTime Modificado)> Firmas(string carpetaRaiz)`: lo ya indexado de una carpeta, para revisar solo lo nuevo o cambiado.
   - `IReadOnlyList<DocumentoIndexado> BuscarPorNumero(string numero, string? carpetaRaiz = null)`: coincidencia **exacta** del número (C7), opcionalmente en una carpeta.
   - Todo con parámetros SQL, nunca concatenando texto.
3. `DocumentosTests.cs`.

## Casos límite

- Guardar dos veces la misma ruta: queda una fila y los números nuevos reemplazan a los viejos.
- Buscar `123` no trae un documento con número `41234` (C7).
- Quitar un documento borra sus números.
- `Firmas` de una carpeta no incluye documentos de otra.
- Una ruta con comillas o `%`: se guarda y se encuentra bien.

## Criterio de término

- Pruebas: `Guardar_reemplaza_por_ruta`, `Busqueda_exacta_del_numero`, `Quitar_borra_sus_numeros`, `Firmas_por_carpeta`, `Rutas_con_caracteres_especiales`. Pasan, junto con todas las anteriores.
- `dotnet build` sin advertencias; `dotnet csharpier check .` sin errores.

# B-005 — Herramientas locales, licencias y estilo

## Objetivo

Dejar fijadas en el repo las herramientas de formato y de licencias, y las reglas de estilo del código.

## Contenido exacto

1. `.config/dotnet-tools.json`: manifiesto de herramientas locales (`dotnet new tool-manifest`) con `csharpier` y `nuget-license` instaladas en su última versión estable (`dotnet tool install csharpier`, `dotnet tool install nuget-license`).
2. `.config/licencias-permitidas.json`: arreglo JSON con los identificadores SPDX permitidos por ser compatibles con GPL v3: `MIT`, `Apache-2.0`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `Zlib`, `MS-PL`, `GPL-3.0-only`, `GPL-3.0-or-later`, `LGPL-3.0-only`, `LGPL-3.0-or-later`.
3. `.editorconfig`: `root = true`; para `*.cs`: indentación de 4 espacios, fin de línea CRLF, UTF-8, `csharp_style_namespace_declarations = file_scoped`, `dotnet_sort_system_directives_first = true`. Para `*.{json,xml,props,csproj,slnx,yml}`: indentación de 2 espacios.

## Casos límite

- Las versiones de las herramientas son estables.
- `licencias-permitidas.json` es un arreglo JSON válido (sin comentarios).

## Criterio de término

- `dotnet tool restore` funciona.
- `dotnet csharpier check .` termina sin errores.
- `dotnet nuget-license -i Hormiguero.slnx -a .config/licencias-permitidas.json` termina sin licencias rechazadas.
- `git status --short` solo muestra los archivos permitidos.
